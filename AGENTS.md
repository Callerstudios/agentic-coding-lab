# Agent Instructions

## Project

This is a small vanilla HTML, CSS, and JavaScript website used to practice agentic coding.

## Technology

- HTML
- CSS
- Vanilla JavaScript
- No frontend framework
- No unnecessary dependencies

## Development Principles

- Inspect existing files before modifying them.
- Prefer simple solutions.
- Keep HTML, CSS, and JavaScript separated by responsibility.
- Do not introduce a library when the feature can reasonably be implemented with browser APIs.
- Do not rewrite working code unnecessarily.
- Keep changes small and focused.

## Learning Mode

I am using this project to learn agentic coding.

When implementing a non-trivial change:

1. Explain what you intend to change.
2. Identify the files you expect to modify.
3. Implement the change.
4. Verify the result.
5. Summarize what changed and how it was verified.

Do not hide errors. If something fails, explain what failed and why.
